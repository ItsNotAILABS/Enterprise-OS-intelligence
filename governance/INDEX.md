## Hierarchy of Instruments

The enterprise governance framework is organized into a strict hierarchy. Higher-level instruments prevail over lower-level instruments in all cases of conflict.

```
Level 0  ┌─────────────────────────────────────────────┐
         │           MASTER CHARTER                     │  Constitutional
         └─────────────────────────────────────────────┘
Level 1  ┌─────────────────────────────────────────────┐
         │        RULES OF PROCEDURE                    │  Constitutional / Procedural / Committee
         └─────────────────────────────────────────────┘
Level 2  ┌─────────────────────────────────────────────┐
         │          CODE OF CONDUCT                     │  Personnel / Ethics
         └─────────────────────────────────────────────┘
Level 3  ┌─────────────────────────────────────────────┐
         │          OPEN DATA POLICY                    │  Openness
         └─────────────────────────────────────────────┘
Level 4  ┌─────────────────────────────────────────────┐
         │    SAFETY RULES & SAFETY OBJECTIVES          │  Safety
         └─────────────────────────────────────────────┘
Level 5  ┌─────────────────────────────────────────────┐
         │         COMPONENT CHARTERS                   │  Organism-specific
         └─────────────────────────────────────────────┘
Level 6  ┌─────────────────────────────────────────────┐
         │       PROTOCOLS & FRAMEWORKS                 │  Technical-operational
         └─────────────────────────────────────────────┘
```
