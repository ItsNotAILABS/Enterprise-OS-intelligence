API
HOSTEX API Endpoints
RESTful API for infrastructure management. Deployed as Cloudflare Worker at the edge.
GET /api/status Worker health + intelligence metrics (heartbeat, Kuramoto sync, Lyapunov stability)
GET /api/domains List all managed domains with health, SSL, and provider information
POST /api/dns/sync Synchronize DNS records across all providers for a domain
POST /api/ssl/provision Provision SSL certificates (wildcard + domain, auto-renew)
POST /api/cdn/purge Purge CDN cache (selective paths or full purge)
GET /api/propagation/{domain} Check DNS propagation status across global resolvers
