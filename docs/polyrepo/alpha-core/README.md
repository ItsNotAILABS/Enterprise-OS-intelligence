# alpha-core

Scaffold generated from the approved polyrepo convention.

## Folder Purpose

- `apps/` — deployable applications and APIs
- `services/` — domain and business service implementations
- `agents/` — autonomous agent implementations and task logic
- `models/` — intelligence models and substrate logic
- `contracts/` — versioned schemas, interfaces, and API contracts
- `infra/` — infrastructure-as-code and deployment configuration
- `docs/` — architecture records, ADRs, and operations documentation
- `tests/` — integration, system, and end-to-end tests

Use this scaffold as the initial layout when creating the standalone `alpha-core` repository.
